

Маршрутизация служебной заявки на Java без Maven

## Реализованные правила
1. Персональные данные -> SECURITY_REVIEW независимо от остальных полей
2. Иначе риск HIGH -> DIRECTOR_REVIEW
3. Иначе сумма от 500 000 включительно -> FINANCE_REVIEW
4. Иначе срочная заявка с суммой меньше 35% от 500 000 (то есть меньше 175 000) -> FAST_TRACK (варикнт 6)
5. Иначе -> STANDARD

Последние два цифры зачётной книжки: 21. Вариант: 21 % 8 + 1 = 6. Так как формулировка модификатора в таблице задания не уточняет единицы измерения, в этой реализации 35 принято как процент финансового порога; это решение зафиксировано в DECISIONS.md

Требуется установленный JDK. Из каталога starter_project выполните:
Запустить `run_selfcheck.bat`. Проверки включают пороговые значения, приоритеты правил, некорректную сумму и отсутствующий уровень риска
