# Практическая работа №8 — Инкапсуляция, enum и управление состоянием объекта


## Сборка и запуск
Требуется установленный JDK (команды выполняются из каталога "starter_project")

Windows: запустить "run_selfcheck.bat"

## Реализованные правила
- id не пустой; даты обязательны; окончание не раньше начала;
- submit: только DRAFT; approve и reject: только SUBMITTED;
- причина отказа содержит минимум 10 символов после удаления пробелов по краям;
- cancel: только из DRAFT,SUBMITTED, APPROVED;
- complete: только из APPROVED, после end, максимум через 35 дней после end;
- открытого setStatus нет, статус меняется только доменными методами;
- BusinessTripService отвечает за поиск и уникальность id, а BusinessTrip — за инварианты заявки

SelfCheck проверяет корректные сценарии и граничные случаи, в том числе 9/10 символов причины и 35/36 дней после окончания.
