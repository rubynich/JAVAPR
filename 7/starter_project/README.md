# Практическая работа 7

Что делает программа
Проект содержит классы для создания товаров и сотрудников, формирования заказа, добавления и удаления позиций, расчёта стоимости и подтверждения заказа. Класс SelfCheck автоматически проверяет основные правила программы.

Можно открыть cmd в папке starter_project и выполнить: run_selfcheck.bat


Что проверяется
SelfCheck выполняет 12 проверок:
1. корректный товар создаётся;
2. отрицательная цена отклоняется;
3. количество 1 принимается;
4. количество 100 принимается;
5. количество 0 отклоняется;
6. количество 101 отклоняется;
7. повторный товар объединяется;
8. объединение повторного товара до 35 единиц разрешено;
9. объединение повторного товара свыше 35 единиц запрещено;
10. итоговая стоимость вычисляется правильно;
11. после подтверждения нельзя добавлять товары;
12. внешний код не может изменить список позиций через getItems().


Правила предметной области
- У товара должны быть непустые ID и название, цена должна быть положительной.
- Количество одной позиции должно быть от 1 до 100.
- Повторный товар с тем же ID объединяется, если совпадают название и цена.
- Правило варианта 6: при объединении повторного товара суммарное количество не должно превышать 35 единиц. Это правило находится в Order.DUPLICATE_MERGE_LIMIT.
- После подтверждения заказ нельзя изменять.
- Общая стоимость рассчитывается методом Order.total() из текущего списка позиций.
- Order.getItems() возвращает неизменяемый список.


Классы проекта
Класс	Назначение
Product	Товар: ID, название и цена.
Employee	Данные сотрудника.
OrderItem	Товар и количество в одной позиции.
Order	Список позиций, добавление/удаление, сумма и подтверждение заказа.
OrderService	Создание заказа и проверка перед подтверждением.
OrderStatus	Состояние заказа: DRAFT или CONFIRMED.
SelfCheck	Автоматические тесты.
